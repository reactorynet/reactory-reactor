# Reactor - Reactory AI Assistant

This module provides AI integration functionality for [Reactory](https://reactory.net).

## Installation

To install the Reactory module, follow these steps:

1. Install the Reactory platform by following the [installation guide](https://github.com/reactorynet/).
2. Clone this repository or download the module files.
3. Copy the module files into the appropriate directory in your Reactory installation.
4. Restart the Reactory server.

## Usage

Once the Reactory module is installed, you can use its features in your Reactory applications. Here are some examples:

### Graph Definitions

The module provides predefined graph definitions that can be used in your GraphQL schema. See the [graph definitions documentation](https://reactory-platform.com/docs/graph-definitions) for more information.

### Workflows

The module includes preconfigured workflows that automate common tasks in your application. See the [workflow documentation](https://reactory-platform.com/docs/workflows) for more information.

### Forms

The module provides ready-to-use forms for capturing user input. See the [forms documentation](https://reactory-platform.com/docs/forms) for more information.

### Services

The module offers various services to extend the functionality of your application. See the [services documentation](https://reactory-platform.com/docs/services) for more information.

### CLI Programs

The module includes command-line interface (CLI) programs that can be executed from the terminal.





Reactor module is a module that enables AI features for the reactory platform.
The module is a commercial license that is not open source.

## Installation

Use the reactory cli to install the module:
  
  ```bash
  reactory install reactor
  ```

## Usage
You can use the module GraphQL API to interact with the module. The module also provides a UI that can be used to interact with the module.

The AI is an integration with OpenAI and you will need to create an account with OpenAI to use the AI features.

## Configuration

Set the following environment variables to configure the module:

```bash
# OpenAI API key
OPENAI_API_KEY=your-openai-api-key
OPENAI_ORG_ID=your-openai-org-id
```
