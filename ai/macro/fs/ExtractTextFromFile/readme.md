# ExtractTextFromFile Macro

Extracts a portion of text from a file between specified line numbers.

## Usage
- **Macro:** `ExtractTextFromFile`
- **Props:** `{ path: string, start: string, end: string }`
- **Returns:** Extracted text as a code block

## Example
```json
{
  "path": "~/Documents/example.txt",
  "start": "10",
  "end": "20"
}
```
