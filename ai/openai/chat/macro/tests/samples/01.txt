# Reactor Module

The Reactor Module is a server module built on top of the Reactory Core which provides additional functionalities and services.

## Overview

The module extends the functionalities provided by the Reactory Core by including the following features:

- A scheduler that can execute workflows periodically or at specific times.
- A logger that can record activity logs or error logs in a central location.
- A notification system that can notify users or external systems.
- A caching service that can store data in memory or disk.
- A WebSocket server that can provide real-time communication to clients.

## Features

The following features are provided by the Reactor Module:

### Scheduler

The scheduler service provides a way to execute a given workflow at specific times or periodically. Scheduling is done using a cron-like syntax to specify rule sets for various intervals of time. The service can also be configured to email user provided activity messages about job success or failure.

### Logger

The logger service provides a mechanism to log activities and errors in a central location. The service can write to different log files, and the log files can be rotated based on size, date, or age. The logger can also be configured to send notifications when certain log events occur.

### Notification System

The notification system provides a way to send notifications to users or other systems. Notifications can be sent via email or through other channels such as SMS or Slack. The service can be integrated with external services via adapters.

### Caching Service

The caching service provides a way to store data in memory or disk. The service supports multiple cache engines such as Redis or Memcached. The service can be used to cache the results of frequently accessed computations.

### WebSocket Server

The WebSocket server service provides real-time communication to clients. It can be used to provide real-time updates to clients or to serve complex dashboards or charts. The service can be integrated with external services via adapters.

## Installation

To install the Reactor Module, use the following commands:

```bash
npm install @reactory/modules-reactor
```

## Configuration

The Reactor Module can be configured using environment variables or configuration files. The following variables are supported:

- `REACTOR_SCHEDULER_ENABLE`: Enable or disable the scheduler service. Defaults to `true`.
- `REACTOR_SCHEDULER_RULES`: Define the rules for scheduling workflows. Defaults to `"* * * * * *"` which schedules the workflow every second.

- `REACTOR_LOGGER_ENABLE`: Enable or disable the logger service. Defaults to `true`.
- `REACTOR_LOGGER_PATH`: Define the path to the log files. Defaults to `"./logs/"`.
- `REACTOR_LOGGER_ROTATE`: Define how logs should be rotated. Possible values are `size`, `time`, or `age`. Defaults to `"size"`.

- `REACTOR_NOTIFICATION_ENABLE`: Enable or disable the notification service. Defaults to `true`.
- `REACTOR_NOTIFICATION_ADAPTERS`: Define the adapters to use for notifications. Defaults to an empty array.

- `REACTOR_CACHE_ENABLE`: Enable or disable the caching service. Defaults to `true`.
- `REACTOR_CACHE_ENGINE`: Define the caching engine to use. Possible values are `memory` or `redis`. Defaults to `"memory"`.

- `REACTOR_WEBSOCKET_ENABLE`: Enable or disable the WebSocket server service. Defaults to `true`.
- `REACTOR_WEBSOCKET_PORT`: Define the WebSocket server port. Defaults to `8080`.

## Usage

To use the Reactor Module, follow these steps:

1. Install the module using `npm install @reactory/modules-reactor`.
2. Configure the module using environment variables or a configuration file.
3. Import and use the provided services in your application.
