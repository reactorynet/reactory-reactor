# Reactor & Fast AI
Reactor will act as a proxy for / management provider for fast ai models.

## Model Training
Reactor can build ML models from natural language model input.
Reactor can train ML models via python interface
## Model Catalog
Reactor catalogues ML models for use case, same as any reactory component, reactor can use the
ML models to answer / provide additional context for interacting generative AIs

## Model Invocation / Processing
Reactor invokes models via proxy class that interface to python using queues.
