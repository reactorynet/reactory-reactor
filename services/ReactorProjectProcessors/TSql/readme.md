# TSqlProjectProcessor

Handles SQL Server (T-SQL) project ingestion for the Reactory platform. Detects T-SQL projects by the presence of .sqlproj or .dacpac files and extracts structure and metadata for the system graph.

- **Supports:** SQL Server, T-SQL
- **Key Features:**
  - Project type detection
  - File/folder structure extraction
  - Integration with the Reactory system graph

See the main class for implementation details and extension points.
