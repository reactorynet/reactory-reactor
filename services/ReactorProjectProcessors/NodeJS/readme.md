# NodeJSProjectProcessor

Handles Node.js project ingestion for the Reactory platform. Detects Node.js projects by the presence of package.json and extracts structure and metadata for the system graph.

- **Supports:** Node.js, JavaScript, TypeScript
- **Key Features:**
  - Project type detection
  - File/folder structure extraction
  - Integration with the Reactory system graph

See the main class for implementation details and extension points.
