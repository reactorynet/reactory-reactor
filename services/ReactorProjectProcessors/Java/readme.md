# JavaProjectProcessor

Handles Java project ingestion for the Reactory platform. Detects Java projects by build files (pom.xml, build.gradle, etc.) and extracts structure and metadata for the system graph.

- **Supports:** Java, Maven, Gradle, Ant
- **Key Features:**
  - Project type detection
  - File/folder structure extraction
  - Integration with the Reactory system graph

See the main class for implementation details and extension points.
