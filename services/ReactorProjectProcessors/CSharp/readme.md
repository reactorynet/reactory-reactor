# CSharpProjectProcessor

This processor handles the cataloging and graph creation for C#/.NET projects in the Reactory platform. It detects C# projects by looking for `.csproj`, `.sln`, or `project.json` files and provides methods for extracting project structure, files, and metadata for system graph ingestion.

- **Supports:** .NET, C# projects
- **Key Features:**
  - Project type detection
  - File and folder structure extraction
  - Integration with the Reactory system graph

See the main class for implementation details and extension points.
