# ReactNativeProjectProcessor

Handles React Native project ingestion for the Reactory platform. Detects React Native projects by the presence of package.json and react-native dependency, and extracts structure and metadata for the system graph.

- **Supports:** React Native
- **Key Features:**
  - Project type detection
  - File/folder structure extraction
  - Integration with the Reactory system graph

See the main class for implementation details and extension points.
