# PythonProjectProcessor

Handles Python project ingestion for the Reactory platform. Detects Python projects by the presence of requirements.txt, setup.py, or pyproject.toml and extracts structure and metadata for the system graph.

- **Supports:** Python, Django, Flask, etc.
- **Key Features:**
  - Project type detection
  - File/folder structure extraction
  - Integration with the Reactory system graph

See the main class for implementation details and extension points.
